Ember 개인정보처리방침

시행일 2026년 11월 5일

한눈에 보기

Ember는 회원 가입이 없고, 광고·분석 도구를 쓰지 않아요. 프로젝트와 설계서는 이 휴대폰에 저장돼요. 아이디어와 설계서를 만들 때에만 입력한 내용이 Claude(Anthropic)로 전송돼요.

Claude로 보내는 내용

질문에 대한 답, 직접 입력한 문장, 첨부한 참고 이미지, 개발자 프로필, 지금까지의 아이디어와 설계서가 요청에 담겨 Anthropic, PBC의 Claude API로 전송돼요. 내 API 키를 쓰면 휴대폰에서 Anthropic으로 바로 보내고, Ember 크레딧을 쓰면 Ember 중계 서버를 거쳐 보내요. 중계 서버는 요청 내용을 저장하지 않고, 크레딧 계산을 위한 사용량(모델, 토큰 수, 시각)만 기록해요. Anthropic은 API로 받은 데이터를 자체 정책에 따라 처리하며, 기본적으로 모델 학습에 쓰지 않아요.

웹 검색

'실제 작품 검색'을 켜 두면 Claude가 참고 작품을 찾기 위해 Anthropic의 웹 검색 기능을 써요. 검색어는 Claude가 만들며 Ember는 검색 기록을 따로 보관하지 않아요.

휴대폰에 저장하는 정보

프로젝트, 설계서, 설정, 사용량 기록은 앱 전용 저장소에 저장돼요. Anthropic API 키, Ember 크레딧 토큰, GitHub 토큰은 Android Keystore로 암호화해 저장하고 다른 앱은 읽을 수 없어요.

Ember 크레딧과 결제

크레딧을 쓰면 설치마다 만드는 익명 ID와 이를 대신하는 토큰이 중계 서버에 등록돼요. 이름·이메일·전화번호는 받지 않아요. 결제는 Google Play가 처리하고, Ember 서버는 크레딧 지급을 위해 구매 영수증(구매 토큰)만 Google Play에 확인해요. 카드 정보는 Ember가 볼 수 없어요.

GitHub 내보내기

GitHub 토큰을 연결하면 설계서를 저장소나 이슈로 보낼 때에만 그 토큰으로 GitHub(api.github.com)에 요청해요. 토큰은 휴대폰에만 저장돼요.

신고와 오류 보고서

AI 결과를 신고하면 고른 이유, 적은 메모, 신고한 내용이 개발자에게 전송돼요. 앱이 멈추면 오류 기록이 휴대폰에만 저장되고, 내가 '보내기'를 누를 때에만 메일이나 공유로 전달돼요.

백업

Android 자동 백업이 켜져 있으면 프로젝트와 설정이 내 Google 계정 백업에 포함돼요. API 키와 토큰은 백업에서 빠져요. 설정의 '파일로 내보내기'로 만든 백업 파일은 내가 고른 위치에만 저장돼요.

보관 기간과 삭제

휴대폰의 데이터는 설정 → '모든 데이터 지우기'나 앱 삭제로 바로 지워져요. 중계 서버의 사용량 기록과 신고 내용은 1년이 지나면 지워요. 1년 동안 쓰지 않은 크레딧 계정도 지우는데, 결제한 계정은 전자상거래법에 따라 결제 기록만 5년 동안 보관하고 나머지 연결 정보는 지워요. 아래 연락처로 요청하면 더 빨리 지워 드려요.

아동

Ember는 만 14세 미만 아동을 대상으로 하지 않아요.

문의

개인정보 관련 문의는 앱 정보 화면의 연락처로 보내 주세요. 방침이 바뀌면 앱과 이 페이지에 먼저 알려 드려요.

Ember Privacy Policy

Effective November 5, 2026

At a glance

Ember has no accounts, ads, or analytics. Your projects and design docs are stored on this phone. What you enter is sent to Claude (Anthropic) only when Ember generates ideas or documents.

What is sent to Claude

Your answers, text you type, reference images you attach, your developer profile, and your ideas and documents so far are sent to the Claude API by Anthropic, PBC. With your own API key, requests go straight from your phone to Anthropic. With Ember credits, they pass through the Ember relay server. The relay does not store request content; it only records usage (model, token counts, time) to calculate credits. Anthropic handles API data under its own policies and does not train models on it by default.

Web search

When 'Search real works' is on, Claude uses Anthropic's web search to find reference titles. Claude writes the queries; Ember keeps no search history.

Stored on your phone

Projects, documents, settings, and usage totals are kept in app-private storage. Your Anthropic API key, Ember credit token, and GitHub token are encrypted with the Android Keystore and can't be read by other apps.

Ember credits and payments

Using credits registers an anonymous per-install ID and a token on the relay server. We never collect your name, email, or phone number. Google Play processes payments; the Ember server only verifies the purchase token with Google Play to add credits. Ember never sees card details.

GitHub export

If you connect a GitHub token, Ember uses it only to call api.github.com when you export a document as a repository or issue. The token stays on your phone.

Reports and crash logs

When you report AI content, the reason, your note, and the reported content are sent to the developer. If the app crashes, a log is saved on your phone and is only shared when you tap Send.

Backups

If Android backup is on, projects and settings are included in your Google account backup. API keys and tokens are excluded. Files made with 'Export to file' are saved only where you choose.

Retention and deletion

Data on your phone is deleted with Settings → 'Erase all data' or by uninstalling. Usage records and reports on the relay are deleted after one year. Credit accounts unused for a year are deleted too; for accounts that made purchases, only the purchase records are kept for five years as required by law. Ask us and we'll delete sooner.

Children

Ember is not directed at children under 14.

Contact

For privacy questions, use the contact in the About screen. We'll announce changes in the app and on this page first.
