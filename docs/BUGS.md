# 알려진 이슈 (9단계 후속 종료 시점)

치명·주요 버그는 발견 즉시 고치고 PROGRESS.md/BALANCE_LOG.md 에 기록했다(예: 25-3 `bet_limit` 진행
불가 버그, 25-4 계약서 얼룩·서명). 아래는 이번 세션 기준 남아 있는 **경미한** 이슈다 — 대부분 이전
단계 PROGRESS.md 항목을 재확인한 목록이고, 이번 세션에 새로 발견한 것은 별도 표시했다.

## 이번 세션에 새로 발견

- **`aggressive` 전략에서 클로버 과다**(신규, 미해결): `stable`/`hot` 전략은 클로버 평균 227개로
  목표(220~245)를 맞췄지만, `aggressive` 전략(더 공격적인 베팅)은 평균 1104개로 여전히 4~5배
  과다하다. 원인은 공격적 베팅이 큰 당첨(자릿수 한 번에 여러 단계 도약)을 더 자주 만들어
  `_check_milestones()` 의 while 루프가 더 자주 여러 번 돈다는 것 — `docs/BALANCE_LOG.md` "최종
  상태" 참고. 연승 길이(`STREAK_LENGTH`)를 베팅 전략과 무관하게 고정 상수로 둔 한계이기도 하다.
- **1F→2F, PH→엔딩 목표 미달 지속**(구조적, 신규 시도 2건 모두 실패): `docs/BALANCE_LOG.md` "시도
  2" 참고. 이번 세션에서 구슬 재질 상한 추가 축소, `bet_limit` 성장률 상향 두 가지를 새로 시도했으나
  개선 없이 되돌렸다.

## 이전 단계부터 이어지는 경미한 이슈 (PROGRESS.md 각 단계 "남은 이슈" 요약, 미해결)

- `UpgradePanel.mode`(STANDARD/MARBLE 탭)는 저장하지 않는다 — 불러오면 항상 기본 탭.
- BIG 이상 당첨 연출·오토스핀 중 패널티 억제는 대화창/계약서 팝업 동안만 적용된다(발생 빈도가 낮아
  범위 밖으로 남김, GDD 16장에 명시).
- 남작 컷신 중 음악 볼륨 덕킹 없음(효과음 `bass_drop` 으로 대체).
- `ContractPopup` 양피지는 `_draw()` 절차적 드로잉(텍스처 자산 아님) — 의도된 단순화.
- 오디오 미리듣기 중 Music 슬라이더는 미리들을 트랙이 없다.
- 효과음·셰이더는 Mesa llvmpipe·더미 오디오 드라이버로만 확인했다(GPU/실제 오디오 장치에서 재검증
  필요 — 클라우드 컨테이너 제약, 사람이 실제 PC 에서 확인해야 함).
- 설정 화면에서 `auto_translate=false` 로 미리 조합해 둔 라벨(예: RESET 입력 안내)은 화면을 연 채로
  언어를 바꿔도 그 자리에서 즉시 재조합되지 않는다(닫았다 열면 반영).

## 이번 세션에 확인/QA 하지 못한 항목 (범위·시간 제약)

다음은 사용자가 요청한 QA 항목 중, 이번 세션의 시간 제약으로 **직접 재생·캡처까지는 못한** 항목이다.
관련 방어 코드(NaN/INF 거부, 저장 파일 손상 복구 토스트 등)는 기존 테스트(`test_game_state.gd`,
`test_save_manager.gd`, `test_offline_income.gd` 등)로 커버되어 있으나, 처음부터 엔딩까지 전체
플레이스루(`tools/capture` 자동 진행 모드)로 층마다 스크린샷을 새로 찍어 육안 검수하지는 않았다:
- 저장 도중 강제종료, 오프라인 30일, 시스템 시계 역행, 대출 중 엔딩, 엔딩 후 무한 모드 장시간
- 언어 전환·창 크기 변경을 화면별로 다시 캡처
- 구슬 12개×더블볼 정산 성능(코드상 `RouletteRules.resolve()` 는 반복문 기반이라 이론상 문제
  없어 보이나 실측은 안 함)

다음 세션(또는 사람의 실플레이 QA)에서 `xvfb-run -a -s "-screen 0 1920x1080x24" godot --rendering-driver
opengl3 -s tools/capture/capture.gd` 로 이어서 확인하는 것을 권장한다.
