# 폴리시 체크리스트 (8단계 4/N)

CLAUDE.md "품질 기준"과 8단계 작업 지시의 폴리시 항목을 모두 나열한다. 상태 표기: ✅ 완료·확인 /
⚠️ 부분 완료(아래에 남은 부분 설명) / ⏸ 이번 세션에서 손 못 댐(이유·다음 담당자가 할 일 포함).

## 1. 기본 테마 · 버튼 상태

- ✅ Godot 기본 테마(회색 버튼 등) 노출 없음 — 1단계부터 전용 `theme_main.tres` 를 프로젝트 기본 테마로 지정,
  `tests/test_ui_assets.gd` 가 모든 `theme_type_variation` 이 실제로 테마에 있는지 매 커밋마다 검사한다.
- ✅ 모든 버튼 normal/hover/pressed/disabled 4상태 + 호버·클릭음 — `AudioManager._on_node_added()` 가 새로
  추가되는 모든 `BaseButton` 에 자동으로 호버·클릭음을 붙인다(예외: `silent_button` 메타).
- ✅ (8단계 4/N 신규) 커스텀 마우스 커서 3종(기본/상호작용 가능/비활성) — `CursorTheme`(ART_BIBLE 16장), 새
  버튼마다 자동 적용.

## 2. 연출 규칙

- ✅ 숫자 변화는 전부 카운트업 트윈(`CountLabel`) — 1~7단계에서 이미 전수 적용, 이번 단계에서 새 숫자 UI를
  추가하지 않았다.
- ✅ 패널 전환 0.15~0.25초 — 기존 `PanelTransition` 규칙 그대로, 8단계에서 새 패널(설정 튜토리얼 체크박스 등)도
  같은 헬퍼를 재사용.
- ✅ 픽셀 퍼펙트(정수 배율·정수 픽셀 스냅) — `2d/snap/snap_2d_transforms_to_pixel`/`snap_2d_vertices_to_pixel`
  프로젝트 설정 + 좌표를 전부 정수로 쓰는 관례, 이번 단계에서 추가한 `TutorialGuide`/`CursorTheme` 도 동일.
- ✅ (8단계 2/N 발견·수정) 반투명 `ColorRect` 오버레이가 world(휠·배경) 위에서 렌더러 조합 특성상 전혀
  합성되지 않는 문제 — `TutorialGuide` 는 완전 불투명(1.0)으로 우회(GDD 19장). **`JackpotOverlay` 는 같은
  증상이 있는데 아직 고치지 않았다** — `spawn_task` 로 별도 작업 제안을 남겼다(task_02aff305).
- ✅ (8단계 4/N 감사) 유휴 동작 반복 억제 — `NeonText.idle_flicker`/마담 벨벳 주기 대사 모두 이미 무작위 간격
  +(벨벳은) 무작위 변형을 쓰고 있음을 확인. 새로 만들 필요 없었다.

## 3. 텍스트 · 국제화

- ✅ 모든 UI 문자열 `tr()` + ko/en 동시 등록 — `test_data.gd` 가 누락을 잡는다. 8단계 1~2/N 에서 추가한 키
  전부 포함.
- ⚠️ 텍스트 넘침·잘림(ko/en) — 이번 세션에서 바꾼 화면(튜토리얼 5종)은 ko/en 둘 다 캡처로 직접 확인해 문제
  없었다. **기존 90여 개 시나리오 전체를 이번에 다시 훑어보진 않았다**(7단계까지 각 단계 종료 시 이미 검수를
  거쳤고 그 뒤 레이아웃 변경 없음) — 9단계 최종 QA 때 전수 재확인 권장.

## 4. 입력 · 내비게이션

- ✅ 키보드 전 기능 접근(스핀·탭 전환·스킬트리·일시정지·오토 스핀·전체화면) — 1~6단계부터 있던 액션.
- ✅ (8단계 4/N 신규) 게임패드 내비게이션 — 커스텀 액션 5개(`spin`/`toggle_auto`/`switch_panel`/
  `open_skilltree`/`pause`)에 조이패드 버튼 추가(GDD 21장). Godot 기본 UI 액션(`ui_accept` 등)은 원래 기본
  조이패드 바인딩이 있어 버튼 포커스 이동은 이미 됐었다.
- ⏸ 실제 게임패드 장치로 손에 들고 확인 — 이 컨테이너에는 연결된 게임패드가 없어 `InputMap` 바인딩이
  등록됐는지(자동 검증됨)까지만 확인했고, 실제 패드로 눌러보는 확인은 못 했다. 사용자가 Windows 에서
  패드를 연결해 확인 권장.

## 5. 사운드

- ✅ (8단계 3/N) SFX 감사 — `AudioManager.SFX`(48개)와 실제 파일·대사 화자 표를 교차 검사해 누락 2건
  (`dialogue_blip_velvet`, `achievement_unlock`) 발견·수정. 나머지는 전부 일치.
- ✅ 반복음 피치 흔들기(`PITCH_JITTER`) — 기존부터 있던 기능, 8단계에서 손대지 않음.
- ✅ (8단계 3/N) 음악 크로스페이드·믹싱 인프라(−12dB 기준, 빅윈·파산 duck, 피버 레이어, 오토 스핀 감쇠) —
  GDD 20장.
- ⏸ **실제 배경음악 파일** — CC0 후보를 조사하려 했으나 이 클라우드 환경의 네트워크 정책이 후보 사이트
  접속을 막고 있다(사용자에게 허용 도메인 확장 요청, 진행 중). 파일이 없어도 게임은 정상 동작(경고만 로그).

## 6. 해상도 · 창

- ✅ 1280×720~4K·울트라와이드 — `viewport`+`keep`+`integer` 스트레치가 창 크기와 무관하게 항상 안전하게
  동작(GDD 21장, 1600×1200 에서 실제 창 캡처로 확인).
- ⏸ **다크 테이블 무늬 레터박싱** — 검은 바 대신 무늬를 넣으려 시도했으나(클리어 컬러 변경) 효과가 없음을
  확인하고 되돌렸다. 진짜 구현하려면 스트레치 모드 자체를 바꾸는 아키텍처 변경이 필요하다(GDD 21장에 왜
  실패했는지, 무엇을 다시 시도해야 하는지 기록). 위험 대비 효과가 낮다고 판단해 이번 단계 범위에서 뺐다.
- ✅ (8단계 4/N 신규) 창이 최소화·비활성 상태면 프레임을 10fps 로 제한, 복귀 시 원래 설정으로 — GDD 21장.
- ⏸ 저사양 60fps·1시간 소크 테스트 — 이 컨테이너는 소프트웨어 렌더러(Mesa llvmpipe)라 실제 성능 측정이
  무의미하고, 1시간 연속 실행도 세션 예산상 비현실적이다. 사용자 실제 PC(저사양 포함)에서 확인 필요.

## 7. 남은 일(우선순위 순)

1. **배경음악 CC0 후보 조사 재개** — 네트워크 허용 도메인이 확장되면 바로 진행(3/N 참고).
2. **`JackpotOverlay` 의 world-위-디밍 버그 수정** — spawn_task 로 제안됨(task_02aff305), 잭팟 중 휠이 안
   어두워지는 문제.
3. 텍스트 넘침 전수 재확인, 다크 테이블 레터박싱 아키텍처 변경, 실기기(게임패드·저사양 PC) 확인 — 전부
   9단계 최종 QA 또는 사용자 직접 확인 항목으로 이관.
