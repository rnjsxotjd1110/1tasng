# 동료 대본 작성 지침 (STARVEIL)

## 세계관
- 100년 전 달이 깨져 조각이 떨어졌고, 그 자리에 밤마다 구조가 바뀌는 **별장막 미궁**이 생겼어요.
- 플레이어 **별지기**는 기억을 잃은 채 **등불 야영지** 입구에서 쓰러져 있었고, 주사위 모양의 별 조각(**운명 주사위**)을 쥐고 있었어요.
- 별지기는 매일 밤 미궁에 들어가 **달 조각**을 모아 달을 되살리려 해요.
- 미궁 4구역: 이끼 정원 → 수정 동굴 → 가라앉은 서고 → 달의 왕좌. 최종 보스는 영원한 밤을 원하는 **밤의 여왕 녹스**.
- 야영지에는 **별빛 수정**(시간이 지나면 달가루가 쌓임)이 있어요. 재화: 달가루(선물·의상), 별조각(영구 성장).
- 전투는 주사위를 굴려 기술 칸에 배치하는 방식이에요.

## 대사 규칙 (절대 규칙 — 한 줄이라도 어기면 안 됨)
1. **모든 문장에 주어를 쓴다.** 한국어에서 흔히 생략하는 주어도 반드시 넣는다. 예: "같이 가자!" ✗ → "우리 같이 가자!" ○ / "배고파." ✗ → "나는 배고파." ○ / 의문문도 "너는 괜찮아?" 처럼.
2. **문장이 '다'로 끝나면 안 된다.** "~했다", "~이다", "~합니다", "~입니다", "~겠다", "~구나 했다" 모두 금지. 반말은 -어/-야/-지/-네/-거든/-잖아/-까 등, 해요체는 -요로 끝낸다. 느낌표·물음표·말줄임표 앞 글자도 '다'면 안 된다("좋다!" ✗, "싫다…" ✗).
3. **단어 하나 뒤에 쉼표를 찍지 않는다.** "응, 알았어" ✗, "아, 그렇구나" ✗, "별지기, 이거 봐" ✗, "그래, 좋아" ✗. 쉼표는 가급적 쓰지 말고, 꼭 필요하면 긴 구절 뒤에만.
4. **추상적·시적인 표현 금지.** "문은 말하지 않아. 그런데 사슬이 당겨." 같은 뜻 모를 비유 금지. 구체적인 사물·행동·감정으로 말한다.
5. 플레이어 대사(s:'me', choices 의 t)에도 1~4 규칙을 똑같이 적용한다.
6. 내레이션은 쓰지 않는다(s:'narr' 금지). 오직 캐릭터와 'me' 대사만.
7. 건전한 순애 로맨스. 성적인 표현·노출 묘사 금지. 귀엽고 따뜻하게.
8. 한 줄(t)은 최대 60자 정도. 모바일 말풍선에 들어가야 함.

좋은 예: "나는 오늘 별사탕을 세 개나 먹었어!" / "저는 이 책을 벌써 세 번째 읽고 있어요." / "손님은 운이 좋은 편이거든?"
나쁜 예: "배고파…"(주어 없음) / "오늘은 좋은 날이다."(다로 끝남) / "응, 그래."(단어+쉼표) / "별이 울고 있어."(추상)

## 출력 형식
`starveil/src/data/heroines/<id>.js` — ES 모듈, `export default { ... }`. 각 대사는 `{ e: '표정', t: '대사' }`, 장면 대사는 `{ s: '<id>' 또는 'me', e: '표정', t: '대사' }` ('me' 줄은 e 생략 가능).

```js
export default {
  id: 'lyra', name: '리라', title: '견습 별마녀',
  profile: '도감용 소개 2~3문장(설명문이라 명사형/요체로 끝냄)',
  likes: '좋아하는 것: ...',
  greet: { low: [6줄], mid: [6줄], high: [6줄] },     // 야영지에서 탭하면 나오는 인사. low=Lv0~3, mid=Lv4~6, high=Lv7~10
  touch: { low: [5줄], mid: [5줄], high: [5줄] },     // 머리 쓰다듬기 반응(건전하게)
  talks: [ 20개 {
    id: 'lyra_t01', minLv: 0,                          // minLv 0~8 고르게 분포
    lines: [1~3줄],                                    // 동료가 먼저 꺼내는 화제
    choices: [ 정확히 3개 { t: '플레이어 대답', aff: 5|2|0, reply: [1~2줄] } ]  // 최고 5, 보통 2, 별로 0 각 1개, 순서는 섞기
  } ],
  gifts: { love: [...], like: [...], dislike: [...] },
  giftLines: { love: [3줄], like: [3줄], neutral: [3줄], dislike: [3줄] },  // {item} 자리표시자로 선물 이름을 넣을 수 있음
  scenes: [ 10개 { lv: 1~10, title: '장면 제목(짧게)', bg: '배경id', lines: [10~16줄] } ],  // 호감도 레벨 도달 시 열리는 이야기. 1→10 으로 관계가 자연스럽게 깊어지고 Lv10 에서 고백
  battle: { start: [4줄], lowHp: [3줄], assist: [3줄], victory: [3줄], defeat: [2줄] },  // 원정 동행 시 짧은 말풍선(30자 이내)
  minigame: { start: [3줄], win: [3줄], lose: [3줄] },
};
```
